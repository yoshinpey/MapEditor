・仕様説明
授業で作成したマップエディタを改造したものです。
クリックした箇所のブロックを追加・削除したり、変更したりすることができます。
また、ダイアログメニューの中から全体編集を行うことも可能です。
編集した地形データはバイナリ形式でセーブ、ロードすることができます。


・操作方法

<カメラ操作>
前後左右移動[W･A･S･D]
回転[ALT]+[左クリック] 
上昇[SPACE]
下降[LSHIFT]

<地形編集>
ブロック単体編集[左クリック]
メニュー(リセット､セーブ､ロード)
プログラム終了[ESC]

<ダイアログ>
・編集モード切替
ブロック種変更､積む､崩す

・全体編集
地形全体の上げ下げができる。

・自然な地形生成
パーリンノイズを使用した、連続的な高低差を作成できる。
基本はランダムで生成を行うが、seed値を設定することで同じ地形を生成することもできる。
また、戻り値に掛ける値の大きさに応じて高低差の緩急を変更することが可能。
↑↑値の変更ですが、残念ながら現状プログラムからしか変更できません。

・高低差を考慮したブロックタイプ
地形全体のブロックタイプを高さに応じて変更できる。
ダイアログボタンで操作が可能。
こちらも先ほど同様、しきい値の変更はプログラムからしか変更できません。
